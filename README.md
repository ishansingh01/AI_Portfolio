# Mainframe — Creative Agency Hero Landing Page

A full-screen interactive hero landing page built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Features

- **Typography**: Helvetica Now Display Medium for branding (`Mainframe®`) and Helvetica Now Display Regular for body copy via WebFonts.
- **Horizontal Mouse-Scrub Video**: Full-screen video background that seeks smoothly forward and backward based on mouse position with seek-flooding prevention.
- **Header & Navbar**:
  - Responsive layout with desktop comma-separated menu and "Get in touch" CTA.
  - Interactive 3-bar hamburger animated toggle with a blurred backdrop overlay on mobile.
- **Hero Section**:
  - Blurred intro label introducing A.R.I.A.
  - Interactive typewriter effect with blinking cursor.
  - Fade-in & slide-up action pills with 4 white buttons and 1 outline email pill button with clipboard copying functionality.

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
